El programa

Cinco sesiones.
Un sistema que funciona.

01

Context engineering: cómo hablarle bien a la IA

La base que hace que todo lo demás funcione

  • Entender qué es el contexto: por qué la IA responde diferente según cómo le escribes
  • Diseño de instrucciones precisas para tareas de tu negocio: correos, informes, análisis
  • Diferencia entre usar IA como buscador y usarla como sistema de trabajo
  • Primeros pasos con Claude: conversaciones, proyectos y memoria contextual
02

Automatizaciones: n8n y Claude working together

Flujos que trabajan solos mientras tú te ocupas de lo importante

  • Qué es n8n: la plataforma que conecta tus herramientas sin escribir código
  • Tu primera automatización real: un flujo que recibe un correo y genera una respuesta
  • Claude code routines: instrucciones que Claude ejecuta de forma consistente y repetible
  • Casos de uso directos: clasificación de facturas, resúmenes de correos, alertas automáticas
03

Tu sitio web, construido con IA

Un frontend real sin necesidad de saber programar

  • Qué es Claude Code y por qué cambia completamente la forma de construir software
  • Diseño y desarrollo de un sitio web funcional desde cero usando lenguaje natural
  • Estructura, estética y contenido: tú decides qué quieres, Claude lo construye
  • Publicación del sitio y preparación para conectarlo con otras herramientas
04

Bots, asistentes y RAGs

IA que conoce tu negocio y responde por ti

  • Qué es un RAG: un asistente que lee tus documentos y responde con esa información
  • Construcción de un bot entrenado con tus contratos, informes o bases de datos
  • Asistentes para atención a clientes, seguimiento de proveedores o gestión interna
  • Cómo actualizar y mantener estos sistemas sin depender de un programador
05

Proyecto de integración: todo conectado

Tu empresa funcionando como un sistema, no como una lista de tareas

  • Automatización completa: Telegram → n8n → GPT → Google Workspace
  • Tu sitio web como punto de entrada: formularios y webhooks que disparan flujos automáticos
  • Panel de control en Google Sheets con todo actualizado en tiempo real
  • Revisión del sistema completo y hoja de ruta para los próximos 3 meses

Antes de empezar

Lo que necesitas saber.

  1. Necesitas activar antes de la primera sesión: Claude Pro, n8n y Google Workspace (Gmail, Drive, Sheets, Docs).
  2. La frecuencia ideal es al menos dos sesiones por semana. Menos de eso fragmenta el avance.
  3. Entre sesiones se requiere práctica autónoma equivalente al tiempo de sesión. Las sesiones muestran el camino, la práctica lo consolida.
  4. El uso intensivo de IA consume tokens a ritmo alto. La disponibilidad de ese recurso depende del plan que el consultante tenga contratado con cada plataforma.
  5. Algunas integraciones generan costos adicionales de terceros: hosting, n8n cloud, APIs. No están incluidos en esta propuesta.
  6. Las consultas entre sesiones se atienden en máximo 6 horas hábiles por WhatsApp o correo.
